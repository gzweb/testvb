# 贪吃蛇 H5

一个无构建步骤、无第三方运行时依赖的静态贪吃蛇小游戏。页面使用原生 HTML、CSS、JavaScript 与 Canvas 2D，可直接部署到静态托管。

## 本地运行

在 `testvb` 目录启动静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000/>，点击「开始游戏」即可。

不需要 `npm install`。`package.json` 只用于声明测试脚本和 ES module 类型。

## 操作

- 方向键或 `W` / `A` / `S` / `D`：转向。
- 手机/桌面屏幕方向按钮：点击转向；按钮触控热区大于 44×44px。
- `P` 或 `Esc`、页面「暂停」按钮：暂停/继续。
- 首屏按 `Enter` / 空格，或点击「开始游戏」：开始一局。
- 结算层点击「再来一局」：无需刷新页面重置对局。

## 规则

- 20×20 棋盘，初始蛇长 3、水平居中、朝右。
- 每颗食物 +10 分并增长一节；步长从 150ms 开始，每次进食减少 6ms，最低 70ms。
- 撞墙或撞到自身非尾格结束；未进食时进入本步即将离开的尾格不算碰撞。
- 禁止 180° 直接反向；每个逻辑步最多消费一次有效转向。
- 切到后台自动暂停，返回后由用户主动继续，不补步。
- 最高分保存在浏览器 `localStorage`；存储不可用时自动降级为本次会话内存值。

## 测试

```bash
npm test
```

测试使用 Node 内置测试运行器，覆盖转向/反向拒绝、进食增长计分、速度下限、墙与自身碰撞、尾格规则、暂停、重新开始、最高分文案及存储异常降级。

静态冒烟：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8000/
```

## 可调参数

棋盘尺寸、初始步长、加速幅度、最低步长和单颗食物分值集中在 `game-core.js` 的 `DEFAULT_CONFIG`。配色、圆角、棋盘响应式尺寸和按钮热区集中在 `styles.css` 顶部的 CSS 自定义属性及媒体查询。

## 范围说明

本轮为静态 H5 最小闭环：不包含 PWA/离线缓存、后端、账号、远端排行榜或音效。音效为可选项，本实现未包含，记为 N/A。需要联网或本地静态服务器首次加载资源；加载完成后的对局不依赖远端业务服务。中文界面附带本地 Noto Sans SC 字形子集（`assets/noto-sans-sc-subset.woff2`，SIL OFL 1.1，许可证见 `assets/OFL.txt`），不请求远端字体。

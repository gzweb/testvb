## 5. 非阻断观察

以下问题已实际复现，但不影响本轮最小验收的通过结论，建议后续迭代处理：

1. **宽屏开局视觉位移**：768×1024 与 1440×900 从首屏进入对局时棋盘上移 `108.6px`，来源是首屏隐藏方向控制区后整体重新居中。无遮挡或不可操作问题。
2. **模态焦点未完全困住**：首屏从“开始游戏”按 Tab 会落到 `BODY`；暂停层从“重新开始”再按 Tab 也会落到 `BODY`。可见控件仍可键盘到达，未阻断键盘闭环。
3. **空白字符检查非零**：`git diff --check` 退出码 `2`，仅报告 `assets/OFL.txt:21` 行尾空白。该文件为字体许可证文本，不影响运行或最小验收。

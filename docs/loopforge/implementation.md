## 3. 实现要点

- 20×20 棋盘；初始蛇长 3、水平居中朝右；食物始终生成在空格。
- 每食物 `+10` 分并增长一节；步长 `150ms` 起，每次进食 `-6ms`，下限 `70ms`。
- 转向仅在 `running` 接受；拒绝直接反向；每个逻辑步最多消费一次有效转向。
- rAF 只负责采样与渲染，逻辑由 accumulator 驱动；单帧最多推进一步并丢弃积压，不补多步。
- 墙、非尾格自身碰撞结束；未进食进入本步将离开的尾格合法。
- `idle → running → paused/running → gameover → running` 闭环；暂停不推进、不缓存转向。
- `visibilitychange` 隐藏时自动暂停，返回后保持暂停并把焦点移到「继续」；继续后重新等待完整步长。
- 最高分使用 `localStorage` 键 `snake-h5.best-score`；读写异常全部捕获并降级到内存最高分。
- 每局开始时保存 `bestAtRoundStart`；结算严格输出「新纪录！」「追平最高分（未破纪录）」「未破纪录」三种文字，覆盖四个边界场景。
- Canvas 按 DPR 调整 backing store；棋盘尺寸同时受视口宽高约束，375～1440px 与低高度横屏均可用。
- 原生按钮、可见焦点、`aria-live` 分数/状态、对话框标题关联、背景 `inert`/降级隔离和开始后焦点移交均已实现。

## 4. 实际验证

命令（工作目录 `testvb`）：

```bash
npm test
```

实际结果：退出码 `0`，`tests 16`、`pass 16`、`fail 0`。覆盖：

- 初始棋盘、蛇长与方向；

- 非 `running` 状态忽略转向；
- 进食增长、计分、食物不重叠、步长 144ms；
- 连续三次进食后 132ms，以及 70ms 下限；
- 撞墙、进入非尾格自身、进入即将离开的尾格；
- 暂停/继续与已生效方向保持；
- 重新开始重置蛇长、分数、方向、速度、食物与状态；
- 四种纪录文案；
- 存储合法值、非法值、写入失败和内存降级。

### 4.3 浏览器交互与响应式

环境：Playwright `1.55.0` + Chromium `140.0.7339.16` headless，Node `v22.23.5`。测试时仅在浏览器路由中注入只读/可控的测试钩子以确定性放置食物和构造碰撞，未把测试钩子写入仓库源码。

结果 `PASS`，实际检查包括：

- 首屏标题、最高分、开始按钮可见；初始焦点在开始按钮；无 console error/page error。
- Enter 开始后焦点移到棋盘；P 暂停后焦点到「继续」，暂停画面 350ms 不变；Esc 继续后焦点回棋盘。
- 向右时按左不反向、不结束；虚拟方向键和触控 tap 均能转向；触控操作不改变页面滚动位置。
- 连续三次进食后分数 `30`、蛇长 `6`、步长 `132ms`；食物不与蛇重叠。
- 撞墙后立即 `gameover`，得分保留；新纪录显示「新纪录！」，写入 `localStorage`，焦点到「再来一局」。
- 再来一局后蛇长 3、分数 0、方向向右、步长 150ms；较低分显示「未破纪录」；正分同分显示「追平最高分（未破纪录）」。
- 刷新页面后最高分仍为 30；存储 getter 抛异常时仍可开始、游玩、结束，最高分降级到会话内存。
- 模拟 `visibilitychange` 隐藏后进入暂停，等待后蛇身坐标不变；返回后焦点到「继续」且不自动恢复。
- 仅用键盘可完成开始、暂停、继续、撞墙结束和再来一局；方向键不产生页面滚动。
- 375×667、390×844、768×1024、1440×900 四视口均无横向滚动，棋盘完整、正方形，方向按钮为 `52×52` 或 `56×56`。
- 补充检查 844×390 横屏：棋盘 `278.8×278.8`、控件无遮挡、无横向滚动。
- 完整交互过程中无 console error、无未捕获异常。

### 4.4 可访问性

- axe-core `4.10.2` WCAG A/AA 扫描：`violations: []`。`color-contrast` 因页面渐变/Canvas 背景被标为 incomplete；已按实际颜色手工核算：正文 `17.89:1`、次级文字 `12.02:1`、主按钮白字 `5.48:1`、强调文字 `12.07:1`，均达到 AA。
- 所有操作控件为原生 `button`；焦点轮廓可见；分数使用 `role="status"` 与 `aria-live`；暂停/结算层使用带标题关联的对话框。

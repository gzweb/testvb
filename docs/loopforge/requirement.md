## 2. 目标与用户

- 桌面或手机用户打开静态页面后，无需登录、无需安装即可完成一局经典贪吃蛇。
- 核心闭环：首屏开始 → 移动/进食/计分 → 暂停与继续 → 碰撞结束 → 查看结算 → 再来一局。
- 页面状态至少包含 `idle`、`running`、`paused`、`gameover`；只有 `running` 接受转向和推进逻辑步。
- 面向普通休闲用户；手机端单手可操作，桌面端键盘可操作。

## 3. 本期范围

### 3.1 纳入范围（P0，除特别标注外）

1. 无构建依赖的静态 H5：`index.html` 加必要的本地 CSS/JS，附 `README.md` 说明启动方式、操作与可调参数位置。
2. 20×20 棋盘；初始蛇长 3、水平居中、朝右；初始得分 0；棋盘始终恰好 1 个食物且不与蛇重叠。
3. 蛇按固定逻辑步长移动；吃食物得 10 分、增长 1 节、重新生成食物并加速。
4. 撞墙或撞到自身非尾格立即结束；未进食时进入本步即将离开的尾格不算自撞。
5. 开始、暂停/继续、结束、再来一局形成闭环；暂停中不移动、不接受转向。
6. 方向键/WASD 与手机四向按钮可用；禁止 180° 直接反向；每个逻辑步最多消费一次有效转向。
7. 初始步长 150ms；每吃 1 个食物减少 6ms，下限 70ms；逻辑推进不得因渲染帧率变化或补帧一次前进多格。
8. 切后台自动暂停；恢复后由用户主动继续，清空旧时间累积，不补步。
9. 本地最高分持久化；读写失败必须捕获并降级为内存值，不阻断游戏。
10. 结算展示本局得分、最高分、纪录文案和「再来一局」；「再来一局」重置蛇长、得分、方向、食物与速度并可立即操作。
11. 基础响应式与可访问性：手机/桌面棋盘和控件不被明显遮挡；控件使用原生按钮、可聚焦且有清晰焦点；分数与结算变化可被辅助技术获取。
12. 自动测试覆盖转向/反向、进食增长计分、墙/自身碰撞、重新开始重置；保留实际命令与输出。
13. 暂停态的额外「重新开始」入口为 P1，不作为本轮最小闭环阻断项。

### 3.2 不纳入范围

- PWA、Service Worker、离线缓存；不保证断网刷新、清缓存后离线打开或硬刷新可加载。
- 后端、账号、多人、远端排行榜、分享战绩、数据库或任何外部 API/CDN/运行时资源。
- 关卡、障碍物、特殊道具、皮肤商城、广告、原生 App、小程序。
- 音效未实现，记为 N/A；不得作为阻断项，不得显示虚假的静音切换成功状态。

## 4. 数值与规则

| 项目 | 规则 |
| --- | --- |
| 棋盘 | 20 列 × 20 行，正方形格，无穿墙 |
| 初始蛇 | 长度 3，朝右，不与食物重叠 |
| 步长 | 初始 150ms；每食物 −6ms；最低 70ms |
| 计分 | 每食物 +10；无连击或时间奖励 |
| 食物 | 棋盘上始终恰好 1 个，仅生成在空格 |
| 转向 | 仅 `running` 接受；禁止直接反向；每逻辑步最多一个有效转向；无效输入不得缓存成后续反向 |
| 结束 | 仅撞墙或自身非尾格；结束后得分不变 |
| 暂停 | 不推进时间、不接受转向；继续后走完整步长 |
| 后台 | `visibilitychange` 隐藏时自动暂停；恢复不补步 |
| 最高分 | 历史最大值；同分不算新纪录；存储异常降级为内存 |

### 4.1 最高分与结算口径

进入一局时保存 `bestAtRoundStart` 快照。结算文案严格按以下四种情况，所有情况都显示本局得分、结算时最高分和「再来一局」：

| 情况 | 条件 | 文案 | 最高分处理 |
| --- | --- | --- | --- |
| 新纪录 | 本局得分 > `bestAtRoundStart` | `新纪录！` | 更新并持久化最高分 |
| 正分追平 | 本局得分 = `bestAtRoundStart` 且得分 > 0 | `追平最高分（未破纪录）` | 保持不变 |
| 低分 | 本局得分 < `bestAtRoundStart` | `未破纪录` | 保持不变 |
| 首次零分 | `bestAtRoundStart` = 0 且本局得分 = 0 | `未破纪录` | 保持 0 |

## 5. 可测试验收标准

以下为本轮硬性验收项。每项必须记录实际观察结果或测试输出；未执行的项写「未验证」，不得写成通过。

本轮主验收环境为本地静态服务器加当前可用的桌面 Chrome/Chromium；手机尺寸与触控交互可用响应式视口/触控模拟检查，真实手机、Safari、Firefox 和读屏软件实测若未执行则列为未验证。

### AC-01 静态交付

- `testvb` 内存在可直接由静态服务器访问的 `index.html` 及所需本地 CSS/JS，无构建步骤。
- `README.md` 给出本地启动命令、基本操作和可调参数位置。
- 页面加载和完整对局不依赖外部 API、CDN、字体、图片或音频等运行时资源。

### AC-02 棋盘、初始状态与进食

- 首屏可见游戏名称、简短玩法说明、最高分（无记录时为 0）与「开始游戏」按钮。
- 开始后为 20×20 棋盘，蛇长 3、朝右，得分 0；食物只有 1 个且不覆盖蛇身。
- 模拟吃到食物后，得分由 0 变 10，蛇长由 3 变 4，食物在空格重生且不与蛇重叠。
- 连续吃 3 个食物后，步长为 132ms（150 − 3×6），且每步只推进一格。

### AC-03 状态闭环

- `idle → running`：点击「开始游戏」后进入对局；焦点不残留在已隐藏的按钮上。
- `running ↔ paused`：暂停按钮及 P/Esc 可暂停和继续；暂停时蛇不移动，显示暂停提示；继续后从原位置、原方向前进。
- `running → gameover`：碰撞后立即停止并展示结算层，得分保持碰撞前数值。
- `gameover → running`：点击「再来一局」后无需刷新，蛇长 3、得分 0、步长 150ms，并可立即操作。
- 开始键仅在首屏开始按钮或非交互区域响应 Enter/空格；焦点在其他原生按钮时保留按钮自身行为。

### AC-04 输入与禁止反向

- 方向键、WASD 和手机四向按钮均可改变方向；按钮为原生 `button`，触控热区不小于 44×44px。
- 蛇向右时按左无效，不反向、不死亡，继续向右。
- 同一逻辑步快速输入多个方向时最多消费一个有效转向；被拒绝的反向不得在后续步生效。
- 方向键操作不滚动页面；仅用键盘可完成开始、转向、暂停/继续和再来一局。

### AC-05 计时、加速与后台恢复

- 初始逻辑步长为 150ms；每次进食减少 6ms；不低于 70ms。
- 渲染帧率变化不改变逻辑速度，不出现一帧多步；后台恢复不补步。
- 切后台或最小化至少 2 秒后返回，状态为 `paused`，蛇未移动；用户主动继续后走完整一步。

### AC-06 碰撞

- 蛇头越出棋盘即结束。
- 蛇头进入自身非尾格即结束。
- 未进食时，蛇头进入本步即将移走的尾格不算碰撞。
- 结束层出现后逻辑停止，不能继续移动或计分。

### AC-07 最高分、持久化与降级

- 获得最高分后刷新页面，首屏最高分仍显示该值；后续更低或同分对局不降低最高分，也不错误提示新纪录。
- 结算文案覆盖新纪录、正分追平、低分、首次 0/0 四种情况，条件与文字见 §4.1。
- 禁用、抛错或不可用 localStorage 时，游戏仍可开始、游玩、结束；异常被捕获，最高分仅降级为内存值。

### AC-08 响应式与基础可访问性

- 在 375×667、390×844、768×1024、1440×900 视口下，棋盘完整可见、不变形、不被主要控件遮挡，且无横向滚动条。
- 手机竖屏可完成全部操作；桌面布局不要求手机方向键始终显著显示。
- 所有可点击控件为原生按钮或具备等价的可聚焦与 Enter/空格触发能力，焦点清晰可见。
- 得分变化与结算结果通过 `aria-live` 或等效机制可被辅助技术获取；正文文本对比度满足 WCAG AA（≥4.5:1）。

### AC-09 自动测试

- 自动测试至少覆盖：合法转向与反向拒绝、进食增长与计分、撞墙、撞自身、重新开始重置。
- 测试节点必须实际运行项目声明的测试命令，保存命令、退出码与关键输出；失败项不得抹去或改写为通过。

### AC-10 静态页面冒烟

- 在 `testvb` 下启动本地静态服务器，请求首页得到 HTTP 200。
- 至少记录实际命令与状态码；若同时检查浏览器控制台，应记录是否出现 error 或未处理异常。

## 6. 产品冲突关闭结论

| 原冲突 | 本轮结论 |
| --- | --- |
| 离线刷新承诺与静态 H5 选择冲突 | 不保证断网刷新；不做 PWA/Service Worker/离线缓存；资源自包含要求保留 |
| 结算是否明确提示未破纪录 | 四种情况均有精确文案，见 §4.1 |
| 结算后再来一局与暂停中重新开始的优先级 | 结算/再来一局为 P0；暂停态额外重开为 P1，不阻断最小闭环 |
| 可选音效与「所有验证必须通过」冲突 | 未实现音效记 N/A，不作阻断项，不伪造开关成功状态 |
| 后台暂停后是否补步 | 自动暂停，恢复清空累积并等待用户继续，不补步 |
| 快速连按造成反向回环 | 每个逻辑步最多消费一次有效转向，无效反向不缓存 |
| 进入即将离开的尾格是否碰撞 | 未进食时不算自撞；进入非尾格仍结束 |
| 开始键与其他按钮的键盘行为 | 仅开始按钮或非交互区域的开局快捷键生效，其他原生按钮保留自身行为 |
| 历史 REJECT 与流程继续 | 保留独立代码评审与人工验收；历史运行成功不等于设计或代码已通过 |

截至本文件定型，上述冲突已收敛，不扩大最小流程验收范围。
